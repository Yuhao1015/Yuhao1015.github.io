01 / 多 Agent 协作平台

Agent Hub

让多个 AI，像团队一样协作。

从一句目标出发，拆解任务、分配 Agent、接力执行，在像素办公室里看见整个协作过程。

  • Multi-Agent
  • Python
  • 异步任务编排
  • 可视化工作流
了解项目

Agent Hub 将目标拆解为有依赖关系的任务，按任务类型与模型能力组织多个 Agent 协作。通过像素办公室、任务依赖图和实时运行日志，查看任务进度与结果，并提供共享上下文、失败降级、断点恢复和成本记录。

  1. 01

    从目标到执行计划

    先澄清目标，再拆解任务；按依赖关系安排执行，可并行的任务同时推进。

  2. 02

    看得见的 AI 协作

    用像素办公室、任务依赖图与实时运行日志呈现执行过程，支持查看历史运行。

  3. 03

    让协作可以持续

    通过共享黑板传递上下文，配合失败降级、断点恢复与成本记录管理执行过程。

02 / 训练与饮食记录小程序

健身达人

让每一次坚持，都看得见。

把训练记录、组间休息、练后餐推荐与成长反馈，放进一个轻量的微信小程序。

  • 微信小程序
  • TypeScript
  • 本地优先
  • 产品交互
了解项目

围绕一次训练前后的使用过程，健身达人将训练计划、重量与次数记录、组间休息和饮食记录串联起来。通过热力图、力量曲线、成就徽章与打卡海报呈现积累，并根据训练部位、体重与目标对练后餐进行规则评分推荐。

  1. 01

    训练过程更连贯

    沿用上次训练数据，记录每组重量与次数，完成后进入休息倒计时，并反馈个人纪录。

  2. 02

    练完，也照顾好饮食

    记录日常饮食，结合训练与个人目标筛选练后餐，支持卡片翻面、收藏与记入今日饮食。

  3. 03

    给坚持具体的反馈

    用训练热力图、力量进步曲线、徽章与邮票风格打卡海报，展示每一步积累。
